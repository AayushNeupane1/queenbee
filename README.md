# QueenBee

A project repository for QueenBee. It is the website built for QueenBee a clothing brand for plus size women. 
It contains the offer, information, and user can place the order.

# Tech Stack 
FRONTEND:
- Next.js 14+ (TypeScript)
- React (built into Next.js)
- Tailwind CSS (styling)
- Framer Motion (animations)

BACKEND:
- Node.js 18+
- Express.js (TypeScript)
- Port: 5000

DATABASE:
- MongoDB Atlas (Cloud)

TOOLS:
- VS Code (code editor)
- Git & GitHub (version control)
- Postman (API testing)
- npm (package manager)
